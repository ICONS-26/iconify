Coding & Technical Prep

A structured Data Structures & Algorithms roadmap, curated YouTube channels and a practice question list to get you interview-ready.

DSA Roadmap

Work through these topics roughly in order — each builds on the last.

1️⃣ Arrays & Strings

  • Two pointers & sliding window
  • Prefix sums
  • Sorting & searching

2️⃣ Linked Lists

  • Reversal & cycle detection
  • Merge & sort operations
  • Fast & slow pointers

3️⃣ Stacks & Queues

  • Monotonic stack
  • Circular queue
  • Next greater element

4️⃣ Trees & BSTs

  • Traversals (in/pre/post)
  • Height, diameter, LCA
  • Binary search tree ops

5️⃣ Graphs

  • BFS & DFS
  • Shortest path (Dijkstra)
  • Union-Find, topological sort

6️⃣ Dynamic Programming

  • 1D & 2D DP patterns
  • Knapsack variants
  • DP on strings

Curated list

Practice Questions

Search these titles on LeetCode / GeeksforGeeks to solve them — links intentionally left for you to attach your team's preferred judge.

1. Two Sum — find indices of two numbers in an array that add up to a target.

Easy · Arrays

2. Reverse a Linked List — both iterative and recursive approaches.

Easy · Linked List

3. Valid Parentheses — check if brackets in a string are balanced using a stack.

Easy · Stack

4. Lowest Common Ancestor of a Binary Tree.

Medium · Trees

5. Number of Islands — count connected components in a grid using BFS/DFS.

Medium · Graphs

6. Longest Common Subsequence between two strings.

Medium · DP

7. Merge K Sorted Lists using a min-heap.

Hard · Heap

8. Word Ladder — shortest transformation sequence via BFS.

Hard · Graphs
